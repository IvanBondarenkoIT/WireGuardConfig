# WireGuard (Docker / Railway)

Секреты **не** хранятся в репозитории. Полный текст `wg0.conf` передаётся в рантайме.

## Railway

1. В сервисе добавьте переменную **`WG0_CONF`**.
2. Значение — весь конфиг WireGuard (как в обычном `wg0.conf`):
   - либо вставьте **многострочный** текст в UI переменных;
   - либо одна строка с переводами строк как `\n` (поддерживается `entrypoint.sh`).

Шаблон полей см. [`wg0.conf.example`](wg0.conf.example).

## Локально (docker)

```bash
docker run --cap-add=NET_ADMIN -e WG0_CONF="$(cat wg0.conf.local)" ...
```

Файл `wg0.conf.local` не коммитьте (он в `.gitignore` вместе с `wg0.conf`).

## Уже утёкший ключ в истории Git?

Если приватный ключ когда-либо попал в публичный репозиторий, **сгенерируйте новую пару ключей** и обновите пиры на сервере — старый ключ считать скомпрометированным. При необходимости очистите историю (`git filter-repo` / BFG).
